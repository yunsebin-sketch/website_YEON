기업 이름 : 미정
키워드 : CONNECT
기업 이념 : 기억으로 사람과 사람을 잇다
기업 철학 : 기억은 사라지는 것이 아니라, 이어지는 것이다.

핵심 사업
이윤 창출 방향
1. AI Memory Avatar - 고인과의 대화
   - 기업의 대표 서비스.
   - 고인의 기억 데이터, 생전 음성, 영상, 기록, 성격 분석 등을 이용해 AI 아바타를 만들어 실제로 4D 공간에서 대화할 수 있게 함
   - 고인의 가족, 지인들이 원할 경우 인당 딱 한 번 이용 가능
   - 미처 하지 못했던 마지막 대화를 하게 해주는 서비스
   - 유족들의 죄책감을 덜어주는 서비스 
2. Memory Archive - 기억 보관
   - 개인의 특정 기억을 보관(기억이 온전할 때 보관할수록 해상도가 높음, 해상도가 떨어지는 부분은 자사가 인위적으로 채워 넣음)
   - 구독 상품으로 월 1회 기억을 다시 체험하는 서비스 이용 가능
   - VIP의 경우 3회 가능, 돈을 더 지불해도 이 이상은 불가능(중독 방지)
   - 본인이 사망한 뒤 지정한 사람에게 지정한 기억 공개 가능 
3. Memory Sharing - 기억 공유
   - 자신의 기억을 다른 사람에게 직접 경험시키는 것
   - 연인 사이의 사람들 저격 상품

사회 공헌 방향
1. Memory Donation - 기억 기증
   - 자신의 기억을 모두가 체험할 수 있는 공공재로 기증
   - ex) 특정 직업의 경험을 교육용으로 기증, 역사적 사건을 직접 경험한 사람이 교육 목적으로 기증
2. Memory Reconstruction - 기억 복원
   - 사고 후 기억 상실, 치매, 뇌손상 등 의료적 문제로 소실된 기억을 복원시킴
3. Memory extraction - 기억 추출
   - 범죄에 연루된 피해자의 기억을 추출해 사건의 진상과 범인을 밝혀냄

설정
시대 : 23세기 전후의 미래(설정 사유: 21세기에 사는 우리들이 가깝다고 생각하지만 닿을 수 없는 미래)
배경 : 고도로 발전한 대한민국, 뇌과학의 신경 기술이 크게 발전한 사회
기업은 사회적으로 높은 신뢰를 받고 있음
기술의 발전을 추구하지만 인간의 삶과 존엄을 더 중요하게 여김(Memory < Connection)
서비스 키워드 : Preserve > Experience > Share > Reconstruct > Connect

웹사이트(홈페이지) UX/UI 아이디어 : 선으로 요소들을 연결, 첫 화면에서 스크롤하면 Memory -(선으로 이어짐)- Connect -(선으로 이어짐)- 기업이름
