Memory Archive

기억하는 것이 아니라, 다시 그 순간으로.

緣YEON의 Memory Archive는 소중한 순간의 기억 데이터를 기록하고 보관하는 개인 기억 아카이빙 서비스입니다.
보관된 기억은 몰입형 감각 재현 기술을 통해 시각과 청각은 물론, 당시의 촉감과 향기, 온도까지 재현하여
마치 그 순간으로 돌아간 것처럼 다시 경험할 수 있습니다.

시간이 지나 기억이 흐려지기 전에, 가장 선명한 모습으로 남겨두세요.

어떻게 진행되나요?

1

기억을 선택합니다.

보관하고 싶은 특정 기억을 선택합니다.
기억이 온전하게 남아 있을수록 당시의 공간과 감각 정보를 더욱 높은 해상도로 기록할 수 있습니다.

2

기억을 기록합니다.

선택한 기억의 신경 데이터를 정밀하게 분석하여 당시의 시각·청각·촉각·후각을 비롯한 감각 정보를 함께 기록합니다.
기록된 데이터는 개인 Memory Archive에 안전하게 보관됩니다.

3

흐려진 기억을 복원합니다.

이미 일부 손실된 기억은 남아 있는 신경 데이터와 기억 전후의 정보를 분석하여 손실 영역을 재구성합니다.
재구성된 영역은 실제 기억과 혼동되지 않도록 원본 데이터와 명확히 구분하여 관리됩니다.

4

기억을 다시 경험합니다.

YEON의 몰입형 기억 재현 시스템은 보관된 기억의 공간과 감각을 재구성합니다.
이용자는 당시 바라보았던 풍경과 들었던 소리뿐 아니라 피부에 닿았던 감촉, 공기의 온도와 향기까지 경험하며 기억 속 순간을 다시 체험할 수 있습니다.
