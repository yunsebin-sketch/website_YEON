AI Memory Avatar

전하지 못한 마지막 말을 전할 수 있도록.

緣YEON의 AI Memory Avartar 서비스는 고인의 기억 데이터와 생전의 음성, 영상, 기록을 바탕으로 한 사람의 기억과 성격을 재구성해 아바타를 만들어냅니다.
재현된 아바타는 4D 공간에서 마주하고 대화할 수 있으며, 남겨진 사람들에게 단 한 번의 만남을 제공합니다.

어떻게 진행되나요?

1

신청 및 이용자 자격 확인.

유족 또는 고인과 생전 관계가 확인되는 사람이 서비스를 신청합니다.
사망 사실, 신청자와 고인의 관계, 이전 이용 여부 등을 확인한 후 이용 자격을 승인합니다.

2

사전 상담.

전문 상담사가 신청 이유와 현재 심리 상태를 확인하고, 서비스의 목적과 과정, 한계를 안내합니다.

3

기억 데이터 재구성.

생전 YEON에 보관된 고인의 데이터를 기반으로, 유족들이 제공한 음성·영상·사진·기록 등의 추가 자료를 분석하여 AI Memory Avatar를 구축합니다.
데이터가 존재하지 않는 기억과 정보는 임의로 생성하지 않습니다.

4

만남 준비.

전문 검증팀이 AI Memory Avatar의 재현 정확도와 데이터 범위를 검증합니다.
이후 이용자에게 최종 안내를 진행하고, 만남을 계속 진행할 것인지 다시 한번 확인합니다.

5

마지막 만남.

緣YEON의 전용 4D 공간에서 Memory Avatar와 직접 마주하고 대화합니다.
마지막 만남은 최대 60분 동안 진행되며, 이용자는 원할 경우 언제든 만남을 종료할 수 있습니다.

6

사후 상담 및 기록 폐기.

만남 이후 전문 상담사와 대화를 진행하며, 일정 기간 동안 후속 심리 상담을 제공합니다.
만남 과정에서 생성된 임시 데이터와 대화 기록은 규정된 기간 이후 안전하게 폐기됩니다.

어떤 원칙을 지키나요?

1

이용자의 선택을 최우선으로 합니다.

이용자는 모든 과정에서 자신의 의사에 따라 서비스를 중단할 수 있습니다.

2

Memory Avatar는 고인 그 자체가 아닙니다.

AI Memory Avatar는 남겨진 기억 데이터를 바탕으로 마지막 대화를 돕기 위해 만들어진 기술입니다. 실제 고인의 의식이나 존재를 재현하지 않습니다.

3

마지막 만남은 단 한 번입니다.

동일한 고인에 대한 AI Memory Avatar 서비스는 신청자 한 명당 단 한 번만 제공됩니다.
어떠한 추가 비용을 지불하더라도 추가 이용은 제공되지 않습니다.
